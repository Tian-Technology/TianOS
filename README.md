# TianOS - 一个简单的 Python 操作系统模拟器

一个基于 Python 和 Tkinter 构建的简单操作系统模拟器，包含桌面环境、文件系统和各类应用程序。

## 环境要求

- Python 3.7 或更高版本
- Windows 操作系统（主要测试平台）

## 功能特点

### 桌面环境
- 美观的全屏桌面界面
- 开始菜单
- 任务栏（显示运行中的应用）
- 桌面快捷方式

### 内置应用
- **文件管理器** - 浏览文件和文件夹，支持右键菜单
- **终端** - 命令行接口
- **记事本** - 文本编辑器
- **计算器** - 简单的计算器应用
- **设置** - 系统设置
- **系统信息** - 显示系统信息
- **任务管理器** - 查看运行中的任务
- **浏览器** - 简单的网页浏览器

### 文件系统
- 完整的文件系统模拟
- 根目录结构
- 用户家目录
- 系统目录

## 安装方式

### 方式一：使用安装程序（推荐）

1. 运行安装程序：
```bash
python setup_tianos.py
```

2. 按照安装向导操作：
   - 选择安装目录
   - 选择是否创建桌面快捷方式
   - 点击"安装"按钮

3. 安装完成后，双击桌面快捷方式运行 TianOS

### 方式二：手动安装

1. 下载文件：
   - 从 http://tiantech.zjjsw.com/download/tianos_v1.0.0.zip 下载文件
   - 解压到任意目录

2. 进入解压后的文件夹，运行：
```bash
python origingui.py
```

## 使用说明

### 启动系统

**Windows:**
```bash
python origingui.py
```

**或者双击桌面快捷方式**

### 基本操作

#### 从 Shell 命令行
1. 系统启动后，按 ESC 或选择 "Exit to Shell"
2. 在 TianOS Shell 中输入命令：
   - `gui` - 进入图形界面
   - `ls` / `dir` - 列出文件
   - `cd <目录>` - 切换目录
   - `cat <文件>` - 查看文件内容
   - `pwd` - 显示当前路径
   - `help` - 查看帮助

#### 在 GUI 桌面
1. 点击桌面图标启动应用
2. 点击开始菜单选择程序
3. 点击任务栏按钮切换窗口
4. 点击关机按钮关闭系统

### 文件管理器操作
- **双击文件夹** - 进入该文件夹
- **双击文件** - 用默认程序打开
- **右键点击** - 显示上下文菜单（打开方式等）

## 开发

### 项目结构
```
tianos/
├── setup_tianos.py    # 安装程序
├── origingui.py       # 启动界面
├── tianos.py          # 命令行 Shell
├── gui/
│   └── gui.py         # 桌面环境
├── desktop/           # 桌面应用
│   ├── filemanager.py
│   ├── terminal.py
│   ├── notepad.py
│   ├── calc.py
│   ├── settings.py
│   ├── sysinfo.py
│   ├── taskmgr.py
│   └── browser.py
└── root/              # 模拟根目录
    ├── bin/
    ├── etc/
    ├── home/
    └── usr/
```

### 添加新应用
1. 在 `desktop/` 目录创建新的 Python 文件
2. 在文件头部添加元数据：
```python
# NAME: 应用名称
# ICON: 📄
# COMMENT: 应用说明
```
3. 实现应用类
4. GUI 会自动扫描并添加到桌面

## 技术栈

- **GUI 框架**: Tkinter
- **开发语言**: Python 3
- **无外部依赖**（纯 Python 实现）

## 系统要求

- Windows 10/11
- Python 3.7+
- 内存至少 128MB
- 磁盘空间至少 50MB

## 常见问题

### 启动后看不到桌面？
确保 Python 版本在 3.7 或以上，并且没有其他错误提示。

### 应用程序无法启动？
检查是否正确安装，尝试手动运行 `origingui.py` 查看错误信息。

### 文件系统在哪里？
在 TianOS 根目录下的 `root/` 文件夹。
